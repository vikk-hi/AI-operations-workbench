# HM 运营工作台整条链路设计（审阅版）

日期：2026-09-26（北京时间）

目标应用：`https://qingmutec.feishuapp.com/app/app_17es2ybencz`

视觉与交互基准：用户提供的 HM 运营工作台 V9 源码包和截图。

## 1. 目标与本轮边界

保留现有妙搭全栈应用的“核心数据、店铺诊断、待办事项”三个主入口，并按 V9 对齐页面内容、默认“咨询深蓝”的视觉及五种主题，同时跑通两条可验收业务链：

1. **大促目标链**：10 月公司目标 → 璇玑目标拆解 → Excel 归档 → 指定审核人在工作台任务详情确认 → 回填 `biz plan目标` 副本 → 核心数据读取 → D11 抢先购目标确认。
2. **临时任务链**：工作台创建竞品收集任务 → 春豌执行并提交结果 → 指定审核人榅桲收到私聊并验收 → 形成并直接创建后续行动任务及回看计划。

到 2026-09-29 验收的是当前发生的节点及可操作的后续计划，不把尚未发生的 D11 活动效果或行动后的经营指标变化标为“已验收”。璇玑直调若无经过验证的受支持接口，明确显示“未接通”；允许人工在璇玑运行并上传产出继续验收确认、回填和读取，二者分开计分。店铺诊断中的行业排名、反超商家仍是标注清楚的演示数据；店内类目优先接真实 BI。

## 2. 总体架构与数据归属

妙搭前端负责 V9 页面、筛选、任务详情和流程进度；妙搭后端负责身份/权限、目标计算校验、任务创建/状态转移、文件登记、通知和数据源配置。妙搭数据库保存工作流状态、源记录 ID、幂等键、版本、审计记录和 BI 读取快照；它不是原始多维表的替代品。外部系统访问只从后端执行，前端不持有飞书或 BI 凭据。

原始飞书多维表只读。运营写入目标、活动计划和任务时使用已复制的 Base；配置页可选择其他副本，启用前校验 Base/table、字段类型、读写权限和样本记录。切换连接不静默迁移既有业务记录，历史任务继续指向原记录 ID。源名、更新时间、最近完整业务日和“真实/暂行/演示/未接通”状态显示在界面。

## 3. 核心数据与目标拆解

公司目标区只显示不含购物金 GMV 和 NET 的 MTD、YTD 目标与实际，不生成公司逐日达成。NET 实际暂用当前天猫日报的 NET/实收字段，界面明示来源；财务口径以后可替换。品牌经营区从 `biz plan目标` 副本读取逐日 GMV、NET、UV、CR、AOV 目标，展示 VS 目标、同比和环比。没有完整基期或目标时显示“数据不足”，不编造比较值。公司区与品牌区视觉和数据模型分开；本次公司月目标只是 **10 月品牌拆解的暂行输入**，不是两套目标永久相同。

璇玑“店铺目标拆解-含活动层级打标一体化流程（v8）”提供每日 GMV 权重与 UV、CR 预测。将每日权重归一化后按公司 10 月 GMV 总目标拆分；每日 NET = 当日 GMV ×（公司 10 月 NET 目标 / 公司 10 月 GMV 目标）；每日 AOV = 当日 GMV /（UV × CR）。分母缺失或非正数时拒绝确认并标出日期。金额以分为单位分摊尾差，保证月 GMV/NET 汇总与目标精确一致；AOV 展示按相应精度四舍五入，但校验用未舍入值。

技能产出先成为 Excel 草稿，存入指定飞书文件夹下的 D11 活动目录；用户榅桲在“待办事项 → 任务列表 → 待我确认 → 任务详情”查看 Excel 与差异摘要，点击“确认回填”或“退回”。确认前不改目标副本；确认时校验 31 个日期无重复/缺失、五项值合法、月合计与公式，记录确认人、时间、版本和文件链接，再按日期更新副本的既有 31 行。单次部分失败时保持“待同步”并可幂等补齐，不能显示已生效。Excel 为留档，副本为工作台读取源。

D11 抢先购自动关联 10 月 15—19 日的暂行品牌日目标；保留 `biz plan` 原活动标签，不覆盖。榅桲在大促任务中确认这五天 GMV 目标是否合适，可直接编辑相关日期的目标，同时必须保持 10 月品牌 GMV 总额不变；不自动分摊其他日期，因为可能存在其他活动。修改需原因、影响预览及版本历史；此后 D11 任务仍保留独立的人工自核节点。D11 只发布用户指定的“大促活动目标制定（618/D11/IP活动）”一条实例，同名重复源行不重复发布，其余 timeline 事项只展示、未分派者显示“待分派”。

## 4. 任务、审核与消息

登录用户映射真实飞书人员 ID。当前“管理员”代表工作台开发身份；其他人员是各自的飞书身份，不以演示姓名替代。任务列表展示真实负责人，并支持按负责人筛选。发布任务时，后端先写一条总表记录以承接已有互链，再向创建人和负责人的个人表写关联记录；同一人创建并执行的普通任务只建一条个人记录。总表不新增列，结果说明、文件链接和审核字段只加在任务 Base **副本**的个人表。稳定任务编号与请求幂等键阻止重复点击/超时重试重复建记录。

跨人任务状态：`待执行 → 已提交/待指定审核人确认 → 退回重交或审核通过 → 已完成`。负责人在个人表标记“已完成”只解释为“已提交”，且需至少有文字说明或文件链接；两者皆无时为“待补交”。指定审核人点击“审核通过”后直接回填所有关联记录，并自动完成其名下对应审核记录，不再要求第二次点击。负责人提交后私聊指定审核人；发布、退回、审核通过分别私聊相关人员。通知失败单列“待重试”，不撤销已成功的任务写入。

非大促验收任务由榅桲创建、春豌负责，使用璇玑“竞品收集”分析天猫“优衣库官方旗舰店”。优先验证工作台按钮直调；不通时春豌在自己的璇玑身份下手工运行，上传完整结果。非任务产出统一存飞书共享文件夹 `临时任务/任务编号/`，任务表存链接而非堆积附件。春豌随结果提出后续行动及建议负责人；榅桲审核时可修改创建人/负责人，并**直接创建**后续行动任务，私聊新任务的创建人和负责人。实际经营效果要等行动执行后、指标/基线/回看日补齐再评估，不在本次伪造结果。

“流程进度”与任务列表读取同一任务状态：团队成员可查看节点、责任人、提交/确认时间和结果链接，并跳转到任务详情；确认按钮只在有权限的指定审核人的任务详情中出现。任务日期、负责人或状态在妙搭与 Base 两端变动需同步；同一字段近同时冲突时暂停该字段同步，保留两边值，由双方确认解决，不使用最后写入者覆盖。已结束任务排期锁定；改期保留原定日期、原因和历史，联动日历、负荷及提醒，但不回写日终冻结快照。

## 5. 店铺诊断、BI 与页面

沿用 V9 的三主入口、五主题、默认“咨询深蓝”及现有任务列表/周日历/团队负荷/流程进度。行业对照上方类目表、下方类目竞争分析及一级/二级类目筛选共享同一选择状态；点击表行或切换筛选均同步更新。商品明细增加一级类目选择。类目键使用 `(一级类目, 二级类目)` 组合，不跨一级合并同名二级类目；BI 结果保留店铺、源组件、时间范围与刷新时刻。指标聚合遵守“先按源粒度汇总再连接”：聚合 CR=买家合计/UV 合计，不平均每日 CR；缺日不补零；市场排名不累加。

BI MCP 已在开发会话中验证可读取 `Daily Report-category`，但开发会话的授权不能默认转移给在线妙搭应用。发布形态优先采用后端受授权的 BI 查询适配器；若现阶段无法取得应用侧稳定接口，则由经授权的同步任务生成妙搭数据库快照，页面读取快照并标注时效。两者均不允许浏览器持有个人 BI token。商品列表以可替换 provider 接口接入；TOP 200 只作为临时过渡，必须标注范围，绝不宣称全量。组件 219088 在 2026-09-26 的 MCP 初查为 0 行，在日粒度复查成功之前保持“待验证/暂无可信数据”状态，不用演示商品冒充真实 BI 商品。

行业排名和反超商家在本轮继续使用显著标注的演示数据。图 2 的真实店内类目不能和演示行业名次混算；各区块分别显示来源标识。

## 6. 验收与发布门槛

验收以真实登录身份、复制表真实记录 ID、飞书文件链接、私聊送达结果和工作台回读为证据，不以静态截图代替。至少覆盖：

1. V9 色调、三个入口、五主题、负责人展示/筛选、类目联动和来源标识；不同飞书用户只见其授权操作。
2. 公司 GMV/NET 的 MTD/YTD 与品牌五项日目标分离；Excel 经审核后目标副本 31 行正确、月合计一致、D11 10 月 15—19 日正确关联。
3. D11 单条任务从任务列表审核，流程进度团队可见且与任务状态一致；退回不得生效，重复确认不得重复回填。
4. 竞品任务创建 → 总表/双个人表互链 → 私聊负责人 → 春豌提交并归档所有输出 → 私聊指定审核人 → 退回/通过通知 → 后续行动任务直接创建并通知相关人。
5. Base 端提交、妙搭端审核、改期与冲突暂停同步均有可回读的状态和历史；失败不显示成功。
6. 璇玑直调、BI TOP 200、行业真实数据分别单列结果；未接通即未通过，不由手动上传、演示数据或其他组件替代。

发布前完成类型检查、逻辑测试、浏览器多身份走查、与源数据抽样对账、失败重试和权限测试。任何测试消息只发给约定的测试人员；不批量发布 89 条 D11 事项，不改原始 Base，不发送虚构业务结果。若 9 月 29 日仍缺璇玑受支持直调接口或 BI 商品组件稳定返回，交付已通过的链路和明确的未通过清单，不宣称整条链路全绿。

## 7. 交付分段

先核对并保全现有工程及线上版本；随后完成 V9 页面与真实身份/负责人、目标副本和审核写回、任务双表/私聊、BI 店内类目、两条验收路径；最后按真实证据发布和回读。每段以独立验证结果前进，未通过项不阻塞无关安全工作。这个文档是设计与验收约定，**不是已经完成或已经发布的状态报告**。
